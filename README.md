# daily_energy
WebApp zur Berechnung von Grund- und Leistungsumsatz sowie Gesamtenergiebedarf

## Berechnung
- Grundumsatz: nach Harris-Benedict-Formel
- Gesamtenergiebedarf: Grundumsatz × (PAL + Sportzuschlag).
- Wasserbedarf: 35–40 ml pro kg Körpergewicht (minus 800 ml, die in etwa durch Ernährung aufgenommen werden).
- BMI-Referenzbereiche nach altersabhängigen NRC-Werten (USA).

Die Aktivitätsstufen orientieren sich an den PAL-Bereichen der DGE. Für die
Berechnung wird der ausgewählte PAL-Mittelwert verwendet; zusätzlicher Sport
erhöht den Faktor um 0,3.
